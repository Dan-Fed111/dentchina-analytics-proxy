# DentChina Analytics — шлюз Render без VPN

Этот сервис проксирует запросы к **существующему** Cloudflare Worker `dentchina-analytics.djfedorov.workers.dev`.

Он не устанавливает новую версию Analytics и не создаёт новую базу данных. D1, логины, пароли, сохранённые данные и текущая синхронизация amoCRM остаются на стороне существующего Worker.

## Проверки и ограничения

- `npm test` запускает шесть локальных тестов; тесты не обращаются к Cloudflare.
- `/_health` проверяет, что процесс шлюза запущен.
- OAuth-переподключение amoCRM через запасной адрес намеренно заблокировано.
- Публичная доступность Render из России должна быть проверена отдельно.
- Бесплатный Render может засыпать после простоя; первый запрос после сна может быть медленным.
- Не добавляйте пароли, токены и клиентские данные в репозиторий.

## Render

- Runtime: Node
- Build: `npm install --omit=dev`
- Start: `npm start`
- Region: Frankfurt
- Plan: Free
- Health check: `/_health`

После деплоя проверьте `https://<service>.onrender.com/_health`, затем откройте корневой адрес и проверьте вход в Analytics.
